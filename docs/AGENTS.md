# AGENTS.md — docs/

This directory holds the agent-facing documentation for the `thunderball`
BOND film package (mission codename DISCO VOLANTE).

Every document in this directory is a hard constraint, not a suggestion.
Start with `agent_instructions.md` (the read-first protocol), then
`architecture.md` for layer boundaries, then `testing_philosophy.md` before
writing any test.

Live test count and achieved coverage are generated into
`docs/_generated/COUNTS.md`; do not hand-author those numbers in prose.
